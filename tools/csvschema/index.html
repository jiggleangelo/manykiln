01 / Supply CSV

Do not paste passwords, one-time codes, card or bank numbers, or ID numbers. Examples on this page are made up.

A selected file takes priority. Decoded chunks stream into the parser; retained rows support export. No file leaves your browser.

02 / Define constraints

Types: string, integer, number, boolean, date, json. Add required, numeric min/max, minLength/maxLength, enum and composite uniqueKeys. Header names are exact; see documentation.

Header and value heuristics can miss private data. Review before sharing. CSV export quotes every field and neutralizes spreadsheet formula prefixes.
