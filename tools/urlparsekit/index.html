Scope & normalization rules

RFC 3986 ASCII URI-reference grammar; percent-encode Unicode and spaces. Schemes and reg-name/IP literal host letters become lowercase; unreserved escapes decode and other escapes become uppercase. Dot segments are removed after unreserved decoding. Default http/https/ws/wss/ftp ports and an empty port are removed; decimal port zeroes are stripped. HTTP-family empty authority paths become “/”. Empty query and fragment delimiters survive normalization. IPv6 brackets survive; no DNS, IDNA, address compression, base resolution or tracking-parameter removal. Relative dot removal can change resolution: normalize absolute URLs when resolution matters.

Port digits follow RFC syntax and are not limited to a transport's 65535 range. IPvFuture is supported; IPv6 zones are outside this RFC. Query editing uses UTF-8, preserving repeated and empty entries; applying no entries removes the query delimiter. An opaque non-UTF-8 escape may parse but cannot be edited. Maximum URL: 65536 characters; editor: 2000 entries. Inputs are never navigated or rendered as HTML.
