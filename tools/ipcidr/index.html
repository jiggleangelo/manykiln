    Calculation rules & export

    IPv6 uses lowercase, longest leftmost zero compression (two or more groups); mapped IPv4 uses ::ffff:dotted-decimal. Zones, brackets, leading-zero IPv4 octets and noncanonical prefix numbers are rejected. Prefix is required.

    Containment includes equal subnets. Mixed families never overlap. Duplicate and contained routes collapse in the summary. VLSM is atomic: any invalid or oversized request clears the entire result. JSON includes details, overlaps, summary and allocations; CSV includes subnet, summary and allocation rows. All counts export as exact decimal strings.
