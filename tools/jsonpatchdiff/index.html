Precise, reversible edits
Supports add, remove, replace, move, copy and exact structural test.
  • ~0 means tilde; ~1 means slash. No URI decoding.
  • - appends only at an array add destination.
  • Every operation runs on a private clone. A failed test or path rolls back the whole transaction.
  • Inverse patches require the original document and include overwritten values.
What “minimal” means
Structural mode keeps common object/array containers and minimizes insertion, deletion and recursive substitution cost for each array alignment. It does not infer move/copy or claim a global optimum. Fewest operations mode is globally minimal: equal documents need zero operations; any unequal document can be replaced in one operation at the root.
Limits & root removal
One million characters per JSON value; depth 64, 50,000 values, 1,000 operations and 50,000 array alignment cells. Excess is rejected. Removed root is an absent document, labelled with exists:false and a null placeholder; it differs from JSON null. The inverse starts with a root add and can restore it from that placeholder. No files are modified and neither input is overwritten by Apply.
