    02 / A deliberate subset

    Supported

    One document. Two-space indentation-based mappings and sequences (one space after a dash), including lists of mappings. String keys, plain or quoted strings, JSON-style double quotes, doubled single quotes, lowercase true/false, null/~ and finite JSON decimal numbers. Flow values must be strict JSON. Comments start with # after whitespace.

    Explicit diagnostics

    Duplicate keys, raw tabs, inconsistent indentation and unsafe numbers are errors. Anchors, aliases, tags, merge keys, directives, document markers, literal/folded scalars and multiline quotes are unsupported and produce line:column errors. NO, yes, on, off, y and n remain strings with portability warnings.

    Output uses lexical sorted keys and two-space indentation. This is deterministic JSON formatting, not RFC 8785. YAML export quotes every key and string, so boolean traps stay strings. Integer-like keys sort lexically too. Input is limited to 131072 characters and 64 nesting levels. No network, storage, libraries or account.
