One input. Five byte formats.

UTF-8, Base64, Base64URL, Hex and URL-percent conversion with byte inspection.

100% offlineMIT originalNo dependencies
Encoding is reversible and provides no encryption. Bytes stay in page memory. Base64 padding and unused bits are checked strictly; binary bytes can be inspected without treating them as UTF-8.

Do not paste passwords, one-time codes, card or bank numbers, or ID numbers. Examples on this page are made up.

Maximum 262144 UTF-16 units. Base64 and Hex require compact input without whitespace. Base64URL accepts correct padding or none. URL-percent treats + literally; this is not form encoding. Non-ASCII literal input must be percent-escaped. UTF-8 decoding rejects malformed bytes and preserves a BOM.
