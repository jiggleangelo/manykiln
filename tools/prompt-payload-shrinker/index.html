Honest limits

  • Token counts are estimates from a simple rule, not an exact count for any model. Real counts can differ by 25% or more. Lossy steps remove information: check the output before sending it.
  • The estimate is a rule of thumb (about 4 letters per token, 3 digits per token), not a real tokenizer. The range shown is +/-25% and may still be wrong.
  • The compact table form is a subset inspired by the open TOON format. The fallback lines that start with "- " followed by JSON are our own extension, so other TOON decoders may not read such output. Check the target tool before relying on it.
  • It helps most with uniform lists of records. Deeply nested or irregular JSON may shrink little or grow slightly, and the table shows that rather than hiding it.
  • Lossy steps drop real information. They are never applied silently: the label and note are always visible beside the chosen step.
  • Text trimming works on lines only. It does not understand code, diffs or logs.
  • Nothing is uploaded, stored or logged. Closing the tab discards everything.
