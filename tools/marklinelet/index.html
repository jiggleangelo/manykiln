    Preview & lint rules

    Checks heading jumps, duplicate generated slugs, broken local anchor links, table widths, untagged fences and trailing whitespace. Duplicate headings get unique anchor IDs. Empty # points to the document top.

    Headings, paragraphs, code, lists/tasks, quote containers, GFM tables, emphasis and links are supported. Raw HTML is literal text. Images and remote links are inert labels. This focused structural parser does not implement every CommonMark delimiter or container edge case; see README.md for the supported grammar.
