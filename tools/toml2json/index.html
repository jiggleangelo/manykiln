TOML ↔ JSON

Strict syntax. Clear diagnostics. Deterministic output.

Offline · TOML 1.0 · No dependencies

Do not paste passwords, one-time codes, card or bank numbers, or ID numbers. Examples on this page are made up.

Plain JSON maps dates/times to strings and loses integer/float distinctions. Unsafe integers and non-finite floats require lossless mode. JSON null is rejected.

Paste TOML to begin, or load the example.

Result

Keys sort by Unicode UTF-16 order at every level. JSON output is stable, two-space indented and newline-terminated. This is deterministic sorted JSON, not RFC 8785 JCS.
