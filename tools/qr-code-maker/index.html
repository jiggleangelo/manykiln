QR code maker

Type or paste content and download a scannable code as PNG or SVG. It is free, with no sign-up, no watermark, no expiry and no scan limit. Nothing is uploaded, stored or logged.

This makes static codes. The content is fixed inside the picture, so it cannot be edited or scan-counted later, and it never expires.

1. Content

Do not paste passwords, one-time codes, card or bank numbers, or ID numbers.

Examples on this page are made up.

The password is stored as plain text inside the code. Anyone who can scan the printed code can read it.

Times are saved as local times with no time zone.

2. Options

Version 1 means the smallest version that fits is chosen automatically. Raise it only if you need a larger, simpler-looking grid.
